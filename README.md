# Nusuk Keys List

🔑 Ribuan Nusuk keys, siap di-copy satu per satu. 📱 Tap **Copy**, pindah ke aplikasi Nusuk, lalu **paste**. Sesimpel itu! ✨

## 🚀 Langsung pakai webnya

### 👉 [Buka Nusuk Keys List](https://fathahnoor.github.io/nkl/)

🌐 Cukup buka link di atas dari browser HP. Tidak perlu download repo, install aplikasi tambahan, atau paham coding. Simpan linknya supaya gampang dibuka lagi! 💫

Web statik ini dirancang untuk memudahkan copy-paste kode ke aplikasi Nusuk, terutama saat kamu punya banyak kode yang ingin dicoba. Daftarnya dikurasi dan diperbarui secara berkala melalui penambahan batch. Tanggal dan jumlah kode bisa kamu lihat di pilihan batch. 🗓️🔄

## ✨ Yang bikin praktis

- 📋 **Copy satu kode**, lalu langsung paste di Nusuk. Countdown **10 detik** menjaga kode tetap terlihat sebelum masuk History.
- 📦 **Pilih batch** supaya kode dari paket lama tidak tercampur dengan paket baru.
- 🔴 **History** membantu melihat kode yang sudah di-copy.
- ↩️ **Undo** kalau ingin mengembalikan kode ke antrean.
- 💾 **Backup & Restore** untuk menyimpan atau memindahkan progresmu.
- ➕ **Tambah batch sendiri** lewat paste daftar atau import file.
- 🌌 **Tampilan dark neon** yang nyaman dipakai di layar kecil.

📊 Snapshot **11 November 2026**: **4.006 kode unik**, terdiri dari batch **1.099 + 1.000 + 1.000 + 907**. Huruf besar-kecil dipertahankan persis. 🔠

💡 Status **Copied** hanya berarti kode sudah di-copy. Penerimaan kode ditentukan aplikasi Nusuk. Daftar ini tidak menjamin kode masih berlaku, bonus, atau hadiah. Gunakan sesuai ketentuan Nusuk. Proyek komunitas ini tidak berafiliasi dengan Nusuk.

## 🧭 Mulai dalam empat langkah

1. 🌐 [Buka webnya](https://fathahnoor.github.io/nkl/).
2. 📦 Pilih batch yang ingin kamu pakai.
3. 📋 Tap **Copy**, lalu paste dan proses secara manual di aplikasi Nusuk.
4. 🔁 Kembali ke web untuk kode berikutnya. Gunakan **Backup** sebelum pindah browser atau perangkat.

🧠 Progres tersimpan di browser yang kamu gunakan. Membuka web di browser lain atau menghapus data browser dapat membuat progres berbeda. Backup dari versi file lokal bisa dipulihkan lewat **Restore** di web ini. 🔐

## 🤝 Buat yang suka ngoding: yuk kontribusi!

Punya kode baru dari post publik? Bantu update keys list lewat [pull request](https://github.com/fathahnoor/nkl/pulls)! 🛠️💚 Kamu juga bisa [buka issue](https://github.com/fathahnoor/nkl/issues) untuk melaporkan bug atau memberi saran.

- 🔎 Sertakan **kode persis**, **URL sumber publik**, dan **timestamp pengamatan**.
- 🔤 Pertahankan kapitalisasi. Saring duplikat terhadap semua batch, termasuk kode yang belum di-copy.
- 📦 Batch tambahan maksimal **1.000 kode**; batch terakhir boleh lebih kecil dengan jumlah yang jelas.
- 🧪 Jangan masukkan kode contoh pengujian ke daftar pengguna.
- 🛡️ Jangan kirim password, token, data akun, atau progres pribadi.
- 🌿 Pengumpulan cukup baca sumber publik. Jangan melakukan spam, otomatisasi redeem, atau melewati pembatasan platform.

Contoh format data ada di [CONTRIBUTING.md](CONTRIBUTING.md). Panduan updater dan arsip pengumpulan tersedia di [Kumpulan-Key](Kumpulan-Key/UPDATE-WEB.md). Pembaruan data ditinjau maintainer sebelum diterbitkan; tidak ada janji jadwal otomatis. 🔄👀
